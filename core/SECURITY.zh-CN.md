## 安全性

微软严肃对待其软件产品与服务的安全性，这包括通过我们的 GitHub 组织管理的所有源代码仓库，
其中涵盖 [Microsoft](https://github.com/Microsoft)、[Azure](https://github.com/Azure)、
[DotNet](https://github.com/dotnet)、[AspNet](https://github.com/aspnet) 和
[Xamarin](https://github.com/xamarin)。

如果你认为在任何微软所属仓库中发现了符合
[微软对安全漏洞的定义](https://aka.ms/security.md/definition)的安全漏洞，请按下文所述方式报告给我们。

## 报告安全问题

**请不要通过公开的 GitHub issue 报告安全漏洞。**

请改为向微软安全响应中心（MSRC）报告：
[https://msrc.microsoft.com/create-report](https://aka.ms/security.md/msrc/create-report)。

如果你希望不登录就提交，可以发邮件到 [secure@microsoft.com](mailto:secure@microsoft.com)。
若条件允许，请用我们的 PGP 公钥加密邮件内容；公钥可从
[微软安全响应中心 PGP 公钥页面](https://aka.ms/security.md/msrc/pgp)下载。

你应在 24 小时内收到回复。如果由于某种原因没有收到，请通过邮件跟进，以确保我们收到了你最初的报告。
更多信息见 [microsoft.com/msrc](https://www.microsoft.com/msrc)。

请尽量提供以下所列信息（能提供多少就提供多少），以帮助我们更好地理解该潜在问题的性质与影响范围：

  * 问题类型（例如缓冲区溢出、SQL 注入、跨站脚本等）
  * 与问题出现相关的源文件完整路径
  * 受影响源代码的位置（tag / 分支 / 提交，或直接 URL）
  * 复现该问题所需的任何特殊配置
  * 复现该问题的分步说明
  * 概念验证（PoC）或利用代码（如有可能）
  * 该问题的影响，包括攻击者可能如何利用它

这些信息将帮助我们更快地对你的报告进行分级处理。

如果你是针对漏洞赏金（bug bounty）提交报告，更完整的报告有助于获得更高的赏金。
关于我们正在进行的项目详情，请访问
[微软漏洞赏金计划](https://aka.ms/security.md/msrc/bounty)页面。
