RetroChimera 逆合成预测

输入目标产物分子 → 预测合成前体，并可视化完整多步合成路径（结构式全程可读）

目标产物输入方式：
ChemDraw 推荐操作：选中结构 → Ctrl+C → 回到这里 Ctrl+V，下方会自动解析出结构式和 SMILES。
若粘贴后没反应，说明这份 ChemDraw 版本把图形写成了私有二进制格式，请改用 右键 Copy As → SMILES，或 File → Save As → CDXML 后拖到此处。
✔ 已识别 CDXML
原子编号可以省略，如 苯甲醛 直接写 O=Cc1ccccc1，不用写成 [CH]1=[CH][CH]...。 输入后会实时校验，有问题立刻提示。
快速示例： 溴代苄醚苯酚 阿司匹林 对乙酰氨基酚 咖啡因 萘普生
模型可能产生幻觉结果：排名越靠后越可能是错误反应。官方建议单个产物最多请求 5–10 个结果， 任何预测在用于真实实验前必须经化学专家验证。
填写的分子会被当作「可直接购买」——搜索到此终止、不再继续往下拆。勾选右侧复选框后，只显示真正用到这些原料的路线（前提是搜索确实探索到了该分支）。
