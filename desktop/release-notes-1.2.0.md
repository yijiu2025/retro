# RetroWeb 1.2.0 (CPU) —— 桌面一键包

**开箱即用的 Windows 桌面版**：解压到**纯英文路径**，双击 `RetroWeb.exe` 即用。
自带便携 Python 3.9 + 全套依赖（torch 2.2.2 CPU / rdkit / syntheseus / retrochimera），
不需要装 Anaconda、不需要配环境。

> 模型权重（约 9GB）**不在包内** —— 首次启动后到「模型设置」页下载，
> 或参照仓库 `models/` 目录说明手动放置。

---

## 这个版本有什么

对应代码 **v1.2.0**（前端 `retroweb` v1.2.0 + 后端 `retro` v1.2.0）。

### ✨ 新建项目支持 CAS 号

输入框除了粘贴结构式，现在直接填 CAS 号就能查：

```
50-78-2
```

识别后会提示「识别为 CAS 号 50-78-2」。容忍 `CAS 50-78-2`、`50 78 2`、全角连字符等写法。

### ✨ 物质查询可选 ChemIndex

输入框下方多了数据源下拉（PubChem / ChemIndex），选择会记住：

| | PubChem | ChemIndex |
|---|---|---|
| CAS → 结构 | ✅ | ✅ |
| 中文名 → 结构 | ✅ | ❌（只认英文名） |
| 熔点 / 沸点 / 闪点 / 溶解度 | 部分 | ✅ 齐全 |
| 危害符号 / 风险代码 / 安全说明 | ✅ | ✅ |

默认 PubChem（覆盖最广、中文名可查）。

## 🔧 相对上一版（1.0.1）的改进

- **修了一个会卡死的 bug**：此前 CAS 校验位算法按「隔位×2」实现，
  用 17 个真实 CAS 号一测只有 6/17 通过。正确算法是**权重递增**
  （从右往左 ×1、×2、×3、×4…）。修正后 17/17 通过。
  这个 bug 会让一些合法 CAS 号被判成「查无此号」。
- **打开画板带不出结构**：输入 CAS 号后点「编辑结构式」原来得到一张空画板，
  现在会先查出结构再带进去。

## 📥 下载与使用

| 项 | 值 |
|---|---|
| 文件 | `RetroWeb-1.2.0-win64.7z`（约 274 MB） |
| 系统 | Windows 10/11 x64 |
| 解压 | 用 7-Zip / WinRAR 解到**纯英文路径**（不要中文、不要空格） |
| 启动 | 双击 `RetroWeb.exe` |

首次启动后：到「模型设置」页下载模型权重（约 9GB），即可开始逆合成预测。

---

## ⚠️ 需要与后端版本配合

本桌面版内置后端 **v1.2.0**。CAS 号 / 名称查询依赖后端的 `/api/substance` 接口 ——
桌面版已内置，无需额外操作。

若你同时单独跑了仓库里的 API 服务，请确认它也是 v1.2.0 或更新。

---

## 🔄 想要 GPU 加速？

CPU 版与 GPU 版**二进制同源**：GPU 版只是多装了 CUDA 12.1 版 PyTorch 到
`data/gpu-pkgs`，启动时自动影子覆盖。可在软件内「模型设置」页按需安装 GPU 包，
或参照 `desktop/RELEASE_SOP.md` 自己造。

本版未随附 GPU 包（体积约 5–6GB，超出 Release 单文件限制，需分卷）。
