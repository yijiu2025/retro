# releases —— 版本发布说明

> 本目录是 `docs/` 的二级入口，逐文件登记。升级前先读对应版本说明。

| 文件          | 一句话用途                                                     |
| ------------- | -------------------------------------------------------------- |
| `v1.1.0.md`   | Linux/Docker 部署、MIT 许可、英文版文档；含两个必读的手动步骤   |
| `v1.1.1.md`   | `core/` 完整性自检工具与文档修正（补丁版，无破坏性变更）        |

## 命名与放置

- 文件名 `vX.Y.Z.md`，与 git tag 一一对应
- 只记「升级者需要知道的事」：破坏性变更、必做手动步骤、修复摘要
- 历史版本**不删**（查证价值）；开发中的版本说明随版本 tag 落地后入库
